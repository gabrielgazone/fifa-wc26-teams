# 📊 Analisador de Dados CSV

App interativo para upload, visualização, transformação e exportação de dados em CSV.

## Funcionalidades

- Upload de um ou mais arquivos CSV
- Visualização com filtros por coluna, intervalo de valores ou datas
- Gráficos interativos (barras, linha, dispersão, histograma, pizza)
- Transformações: criar colunas, agrupar, renomear, remover
- Relatório em PDF com resumo estatístico e gráficos

## Como usar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```
